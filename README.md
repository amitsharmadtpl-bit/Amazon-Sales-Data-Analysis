# 📊 Amazon Sales Data Analysis (ETL & Dashboard)

## 🎯 Project Objective
The goal of this project was to extract messy e-commerce sales data, clean it using Excel's ETL processes, and build an interactive Executive Dashboard to analyze product discount trends.

## 🛠️ Skills & Tools Used
* **Tool:** Microsoft Excel
* **Data Cleaning (ETL):** Find & Replace, Text to Columns (Delimiters), Removing hidden characters/spaces.
* **Data Profiling:** Handling character encoding errors (e.g., â‚¹), identifying outliers, and deleting corrupted rows.
* **Logical Formulas:** Used `Nested IF` and basic mathematical functions to categorize deals.
* **Data Visualization:** Built dynamic Pivot Tables, connected Pie Charts, and Slicers.

## 🚀 Key Steps Performed
1. **Cleaned Formatting Issues:** Removed rogue currency symbols and commas to convert text strings into actionable numbers.
2. **Text Splitting:** Used 'Text to Columns' to extract the 'Main Category' from messy string blocks separated by pipe `|` delimiters.
3. **Applied Business Logic:** Created a new `Discount Amount` column and used a `Nested IF` formula to categorize them into "Super Deal", "Good Deal", and "Normal Deal".
4. **Built Interactive Dashboard:** Used a Dynamic Table (`Ctrl+T`) to feed a Pivot Table, visualizing the deal distribution via a Pie Chart controlled by a Category Slicer.
